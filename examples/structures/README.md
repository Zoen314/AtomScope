# Synthetic molecular motifs

`molecules.POSCAR` contains 16 atoms in an 11 angstrom cubic cell: one C, one N, one O, one P and twelve H atoms, arranged as methane-, ammonia-, water- and phosphine-like motifs.

The coordinates were constructed for interface demonstrations. They are not an optimized structure, simulation snapshot, reference dataset or claim about thermodynamic stability. Periodicity is enabled by the POSCAR viewer's default interpretation.

The main README's overview screenshot uses this file and the default display settings. Measurement screenshots use the synthetic fixtures in `tests/fixtures/`.
